Confie's Driving School Website

This is a free static website designed for GitHub Pages.

## Publish on GitHub Pages
1. Create a public GitHub repository, for example `confies-driving-school`.
2. Upload `index.html` and `style.css`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide your free website address.

## Before publishing
Replace:
- "Add your number here"
- "Add your town or area here"
- "Add your operating hours here"

You can also add a real WhatsApp link once you have the phone number.
